## §0 一句话

固定带宽 KDE 把数据方差**确定性地**抬高 bw²（每个 realization 都抬，与 N、与随机性无关）。当端元间距小到 raw-σ 字典的混合方差**够不到**这个被抬高的数据方差（方差亏损判据 (μ_K−μ̄\*)(μ̄\*−μ₁) < bw² + Var_{w\*}(μ)），总体 KL 极小点为了尽量放大模型方差，把权重**全压到两个极端端元** {1, K}（中间端元权重精确 = 0，KKT slack η_j > 0 认证）。于是 (K−1) 维切空间里**只剩 1 个活动方向** d = (e₁−e_K)/√2；ŵ 的涨落被锁死在 d 上，协方差 rank-1。任何 ⊥ d 的模（K=3 时即曲率 (1,−2,1)）**统计方差精确为 0**——这就是 F4，但正确表述是 active-set，不是低通。

## §1 设定与记号（与 bounds 实验逐字对齐）

- 字典：K 个**等-σ 高斯密度** h_k(t)=φ(t;μ_k,σ)，等间距 μ_k = μ₁+(k−1)Δμ，面积归一。相邻 KS 距离 ρ 满足 Δμ = 2√2·σ·erf⁻¹(ρ)（引理1 (i)；小 ρ：Δμ ≈ σ√(2π)·ρ）。
- 真权重 w\* 在**开**单纯形内部；样本 = N 颗 i.i.d. 年龄 ~ 混合 g\* = Σ_k w\*_k h_k。
- 观测 **X = N 颗年龄的高斯 KDE（带宽 bw>0），面积归一**。总体（N→∞）极限：
  **p(t) = Σ_k w\*_k φ(t; μ_k, σ_eff)，σ_eff = √(σ²+bw²)**（KDE = 经验测度 ⊛ N(0,bw²)，把每个分量从 σ 加宽到 σ_eff）。
- 估计量：**ŵ = argmin_{w∈Δ^{K−1}} D_KL(X ‖ q_w)，q_w = Σ_k w_k h_k**，用 **raw-σ** 字典 h_k（**不是** σ_eff——这是 dz-unmix-cg 的真实做法）。固定 H 时 KL 对 w 凸 ⟹ 全局唯一极小。
- 切空间记号：T = {v∈ℝ^K : Σv_i = 0}（dim K−1）。模向量：pairwise/extreme-diagonal **d = (e₁−e_K)/√2**；曲率 **c = (1,−2,1,0,…)/√6** 等。

**指标矩记号**（§3.3 用）：以 k−1∈{0,…,K−1} 为位置坐标，记 k̄ = Σ_k w\*_k(k−1)，V_k = Σ_k w\*_k(k−1)² − k̄²，**指标亏损系数 D := (K−1−k̄)·k̄ − V_k**。

## §2 主结果（三级严格度，按对抗自检裁定）

> 标注约定：**【严格】** = 闭式证明 + 机精数值核验；**【小ρ主阶】** = 在 ρ→0（Δμ→0）展开下证明，有限 ρ 为标度代理；**【数值认证·解析 open】** = N1–N4 + 独立复核坐实，第一性原理证明未完成。

**定理（active-set 冻结）.** 等-σ 等间距高斯字典、bw>0、w\* 内部。存在 ρ_c = ρ_c(bw, w\*, K) > 0 使得当相邻 KS 距离 ρ < ρ_c：

**(a) 总体钉扎.** 总体 KL 极小点 w_∞ = argmin D_KL(p‖q_w) 恰支撑在两个**极端**端元 {1,K}：w_∞ = (a,0,…,0,1−a)，内部 KKT slack η_j > 0（边界全局极小，凭 KL 在单纯形上的凸性）。
　- 【严格】活动集 KKT 条件（survivor I₁=I_K，pinned I_j < I₁）；方差-LP 极大化唯一落在极端对 {μ₁,μ_K}，其方差 = (μ_K−m)(m−μ₁)（精确恒等式）。
　- 【小ρ主阶】a → (μ_K−μ̄\*)/(μ_K−μ₁)（均值匹配）；释放判据见 (a′)。
　- 【数值认证·解析 open】有限 ρ 下每个内部 slack 严格 > 0（n2 实测 min η = 1.11×10⁻⁶ > 0，K=3/4/5、对称/非对称全测到）；以及把「主阶极小点 = 顶点」升级到「有限 ρ 全泛函极小点 = 顶点且 slack 严格」的二阶 KL 余项一致界。

**(a′) 方差亏损判据 + ρ_c 闭式【小ρ主阶】.** 钉扎 ⟺ (μ_K−μ̄\*)(μ̄\*−μ₁) < bw² + Var_{w\*}(μ)，等价 **bw² > Δμ²·D**（需 D>0）。闭式阈值
　　**ρ_c = erf( bw / (2√2·σ·√D) )**，小ρ：ρ_c ≈ bw/(σ√(2πD))。
对 N1 的 K=3（w\*=[.25,.4167,.3333], σ=25, bw=12）：D=0.41667 ⟹ Δμ_c=18.59、**ρ_c=0.2900**，与 N1 实测释放区间 (0.25 pinned, 0.30 interior) 吻合。

**(b) 有限-N 确定性活动集【条件严格，依赖 (a)】.** KDE 对**每个** realization 的密度方差精确加 bw²（与 N 无关、确定性，非统计涨落）⟹ 方差亏损逐样本成立 ⟹ 活动集 {1,K} 与 realization 无关 w.p.→1 ⟹ ŵ(X) 落在面 span{e₁,e_K}∩Δ（一维线段），涨落只沿单一切向 d。

**(c) Rank-1 协方差 ⟹ 冻结【条件严格】.** ŵ − w_∞ = β(X)·d（一阶），故 Cov(ŵ) = Var(β)·dd^T **rank-1**，range = span{d}。对任意切向模 v：**std(v·ŵ)/std(d·ŵ) = |v·d|**。⊥ d 的模在 active-face 模型里方差**精确 0**（实测 realized 估计量里为机器零，frozen/live std 比 ~10⁻⁴⁹…10⁻¹¹³，残差 = 死端元在 ~10⁻¹³⁰ 量级的抖动）。

**(d) K=3 推论 + K≥4 修正【严格·有限线代】.** 切向模 v 冻结 ⟺ **v·d = 0 ⟺ v₁ = v_K**。维数分解：1 活（span d）+ (K−2) 冻结 + 1 被 sum-to-one 删除 = K。
　- **K=3**：d ∝ (1,0,−1)，曲率 (1,−2,1) 有 v₁=v₃=1 ⟹ ⊥ d ⟹ **方差冻结**（= F4）。注意这是 K=3 巧合，且冻结的是**方差**——曲率模的**均值**是非零常数 1/√6（在面上 (1,−2,1)·(a,0,1−a) = a+(1−a) = 1，与 a 无关）。
　- **K≥4**：曲率**不** ⊥ d（K=4：(1,−2,1,0)·(1,0,0,−1)=1）⟹ **活的**，幅度 = pairwise 的 **|c·d| = 1/√12 = 0.288675**（与 N3 逐位吻合）；而**内部**一阶差 (0,1,−1,0) 有 v₁=v₄=0 ⟹ **冻结**（N3 实测 0）。⟹ HANDOFF/§0.5a「二阶及以上差分模冻结」**对 K≥4 错**，正确不变量是 v₁=v_K。

**幅度（指向待办 3，非本证明）**：Var(β) ~ ρ⁻²/N（N1 斜率 −0.95、N4 N^{−0.5}）⟹ σ_err = √Var(β) ~ ρ⁻¹/√N，与 K 无关。解析前因子 c 是待办 3。

## §3 证明

### §3.1 KDE 确定性方差膨胀【严格】

设 N 颗年龄 a₁,…,a_N，经验测度 μ_N = (1/N)Σδ_{a_i}。高斯 KDE 密度 X(t) = (μ_N ⊛ φ_{bw})(t)，即 X 是「随机变量 A（取经验分布）+ 独立 N(0,bw²) 噪声」之和的密度。由全方差律，X 作为密度的方差
　　Var_X = Var(A) + bw² = s²_N + bw²，
其中 s²_N = 样本年龄方差。**bw² 这一项是确定性的、与 N 无关、对每个 realization 都加**（不是 O(1/√N) 涨落）。总体极限 Var_p = Var_{w\*}(μ) + σ² + bw²。
〔ref_d2 PROBE E：有限面积归一网格上 Var(q_w)=σ²+Var_mix(w) 与 Var_X=s²_N+bw² 均精确到 1.1×10⁻¹³。〕

**推论**：raw-σ 模型 q_w 的方差 = σ² + Var_mix(w)（Var_mix = Σw_kμ_k² −(Σw_kμ_k)²，纯混合方差），其**上确界**（见 §3.2）= σ² + (1/4)(μ_K−μ₁)² = σ² + O(Δμ²)。数据方差 = σ² + bw² + O(Δμ²)。**bw² 是 O(1) 的硬 gap**，Δμ→0 时模型方差够不到 ⟹ 钉扎（§3.3）。这就是为什么有限-N 也稳（gap 是确定性的，不是要靠 √N·slack 压住涨落）——N4 实测 N=500 也 0 逃逸，正因如此。

### §3.2 方差-LP 包络：极端端元唯一最大化【严格】

固定模型均值 m = Σw_kμ_k，最大化混合方差 = 最大化 Σw_kμ_k²（减去常数 m²）。这是**线性**泛函在多胞形 P_m = {w : Σw_k=1, Σw_kμ_k=m, w≥0} 上的极大 ⟹ 顶点解（Bauer 极大原理）。P_m 有 2 个等式约束 ⟹ 顶点支撑 ≤ 2 点。两点律 {μ_i,μ_j} 均值 m 的方差 = (μ_j−m)(m−μ_i)，对端元对取最宽的 {μ₁,μ_K} 最大。故
　　**max_{w∈Δ, mean=m} Var_mix(w) = (μ_K−m)(m−μ₁)，唯一取在极端对 {1,K}，a=(μ_K−m)/(μ_K−μ₁)。**
〔ref_d2 PROBE：LP 与解析包络 max|·|=2.27×10⁻¹³，支撑恒 {0,K−1}，K=3/4/5 × 多 m 零反例。恒等式 a(1−a)(μ_K−μ₁)² = (μ_K−m)(m−μ₁) 机精（本 session 复核 diff = 0）。〕

于是 q_w 可达 (mean, variance) 区域的**上包络** Env(m) = σ² + (μ_K−m)(m−μ₁)。

### §3.3 方差亏损判据 + ρ_c【小ρ主阶】

数据点 (μ̄\*, σ²+bw²+Var_{w\*}(μ))。落在可达矩区域**之上** ⟺
　　bw² + Var_{w\*}(μ) > (μ_K−μ̄\*)(μ̄\*−μ₁)。
以位置坐标 (k−1)、除以 Δμ²：bw²/Δμ² + V_k > (K−1−k̄)k̄，即 **bw² > Δμ²·D**，D = (K−1−k̄)k̄ − V_k（需 D>0）。代 Δμ = 2√2σ·erf⁻¹(ρ) 解出阈值
　　**ρ_c = erf( bw / (2√2·σ·√D) )。**

**为何「数据矩在包络外」⟹ KL 极小点钉在极端面**：小 Δμ 下 p 与所有 q_w 都是窄高斯族，KL(p‖q_w) 由均值、方差失配主导（2 阶矩展开；匹配均值后 KL ≈ ½[σ_eff²/Var(q_w) − 1 − log(·)] + 均值项，在 Var(q_w) < σ_eff² 区单调递减于 Var(q_w)）。方差够不到 ⟹ KL 推 q_w 到**最大方差边界** = 极端面。**【严格仅在 (mean,var) 矩松弛下；全 KL 泛函的边界选择是数值认证·解析 open】**——ref_d2 PROBE B（K=4 ρ=0.08）：全单纯形 KL 极小落在极端面 {0,3}（KLmin 6.87×10⁻³）胜过次优面 {1,3}（1.21×10⁻²）；PROBE G：极小点方差饱和 Env，残差随网格加密 2.4×10⁻⁸→4.2×10⁻⁹ → 机器零，支持「精确饱和」但非解析证明。

**小ρ 存在性【严格部分】**：LHS=(μ_K−μ̄\*)(μ̄\*−μ₁)=O(Δμ²)→0，RHS≥bw²>0，故 **∃ρ_c>0 使 ρ<ρ_c 必亏损**——钉扎在 ρ→0 邻域**被保证**（模严格度只差矩松弛→全 KL 那一步）。

**判据强度（诚实标注）**：
- ρ_c 是**矩判据**，与 n2 runner 的 rho_pred **同式**（agreement 1×10⁻¹³ 是**重言**，非验证）。真正的检验是对真实 KL 释放 ρ\*_obs：**9/10 配置过预测**（relerr 1.3–9.4%，bw∈{6,12}），唯一欠预测 = K=5,bw=6（−1.9%）；bw=24 过预测 24–29%（矩判据忽略 KDE 引入的 4 阶峰度过剩，需 4 阶矩修正）。
- 小ρ 律精度由 bw/(σ√D) 控制（非单看 bw）：K=5,bw=6 误差 0.11%，K=3,bw=24 误差 9.3%；大 K（大 D）在固定 bw 下更紧。
- 需 D>0；w\* 集中于极端时 V_k→上界、D→0⁺（ρ_c→∞，全 ρ 钉扎）——非近均匀 w\* 未测。

### §3.4 KKT 边界最优性 + 严格 slack

总体目标 f(w) = −∫ p log q_w（去掉常数）。∂f/∂w_k = −∫ p·h_k/q_w =: −I_k。单纯形约束 min 的 KKT：survivor（w_k>0）满足 I_k = I₁ = I_K =: 公共值；pinned（w_j=0）满足 **I_j < I₁**（严格 ⟺ 严格 slack η_j ∝ I₁−I_j > 0）。
〔这与乘性更新不动点 W·((X/q₀·Hᵀ)/Hsum)=W 一致；slack 的可测形式 **η_j = 1 − [((p/q₀)Hᵀ)/Hsum]_j**（n2 定义）。ref_d1：n2 全部 82 cell survivor I=1、pinned I<1（唯一例外是 (K=5,bw=6,middle) 一个 1×10⁻⁶ 收敛 artifact，benign）。〕

**对称 K=3 闭式 slack【小ρ主阶，仅对称】**：w\*=(c,1−2c,c)（⟹ a=1/2，μ₂=μ̄\*），
　　**η_mid = Δμ²·deficit/(2σ⁴) + O(Δμ⁴)，deficit = bw² − (1−2c)Δμ²**，
常数 **1/2 精确、与 c 无关**（Richardson R₀ = 0.49999998，独立 Gauss-Hermite 求积复核；(ratio−½)/Δμ² → −1.83×10⁻³ 是有限 O(Δμ²) 修正）。

**⚠ 非对称 / K≥4 不可用此闭式常数（对抗自检 caught）**：把 1/2 搬到非对称「middle」会**错**——η_exact/η_pred Richardson 外推 → 0.0545（bw=6）、0.187（bw=12），**不是 1**，且依赖 bw。机理：μ₂ ≠ μ̄\* 时曲率 Hermite 权重须绕 μ₂（非 μ̄\*）展开、a≠½ 改 q₀ 展开、偏心一阶项进 η₂。**故非对称 + K≥4 只给 sign(η_mid) = sign(deficit)（小ρ主阶）+ 数值解 exact η_mid。** 一般 K、非对称 w\* 的有限 ρ 严格正性 = 数值认证·解析 open（n2 min η = 1.11×10⁻⁶ > 0）。

### §3.5 有限-N 活动集确定性 + rank-1【条件严格，依赖 (a) 给出 η\*>0、ρ_c】

由 §3.1 方差亏损逐 realization 确定性成立。每 realization 的 KKT slack = η\*_j + O_p(1/√N)（有界 score h_k/q_w 的 CLT；σ>0 给正则性）。故 N ≫ (1/η\*)² 时活动集 {1,K} 与 realization 无关 w.p.→1，ŵ 落在线段 [e₁,e_K]——**一维**活动面，切向 span{d}，d=(e₁−e_K)/√2。一阶线化：ŵ − w_∞ = β(X)·d（内部坐标被严格 slack 钉在 0，sum-to-one + 2 survivor 留**恰好 1** DOF）。⟹ **Cov(ŵ) = Var(β)·ddᵀ rank-1。**
〔N4：1−η_kkt = 收敛后每步 pinned 坐标乘性衰减因子 ratio₁，到 0.0 精度（log 衰减率 = η）；解释「ill 区需 n_iter≥4000」= n_needed ≈ log(w₀/ε)/η，与 4000·η 在 ρ=0.13 才过 ~30 一致。**precision-of-language**：是 per-iterate 因子 = 1−η / log 率 = η，不是 r_per_block=0.84 那个量。〕

### §3.6 模代数 + 冻结不变量【严格·有限线代】

Cov rank-1 ⟹ 任意切向 v：Var(v·ŵ) = (v·d)²·Var(β)，std(v·ŵ)/std(d·ŵ) = |v·d|。**v 冻结 ⟺ v·d = 0 ⟺ v₁ = v_K**。冻结子空间 {v∈T : v₁=v_K} 维数 K−2。逐模（机精到 1.1×10⁻¹⁶，对齐 N3）：

| 模 v（K=4） | v₁=v_K? | \|v·d\| | 裁定 |
|---|---|---|---|
| d=(1,0,0,−1)/√2 | — | 1 | **活**（唯一） |
| 曲率 (1,−2,1,0)/√6 | 1≠0 | **1/√12=0.288675** | **活** |
| 曲率 (0,1,−2,1)/√6 | 0≠1 | 1/√12 | **活** |
| 内部一阶差 (0,1,−1,0)/√2 | 0=0 | **0** | **冻结** |
| 边一阶差 (1,−1,0,0)/√2 | 1≠0 | 1/2 | 活 |
| K=3 曲率 (1,−2,1)/√6 | 1=1 | **0** | **冻结**（= F4，巧合） |

⟹ **HANDOFF 待办 1「一阶差活、二阶及以上差冻结」与 §0.5a/F4「曲率及以上冻结」对 K≥4 错**（K=4 曲率活、内部一阶差冻结，恰好反过来）。正确：**v 冻结 ⟺ v₁=v_K**。

## §5 与 σ_err ~ ρ⁻¹（待办 2/3）的衔接
