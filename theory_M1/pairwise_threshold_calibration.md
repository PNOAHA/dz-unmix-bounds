## §0 一句话

待办 1 钉死了「**哪个模携带涨落**」= 唯一活模 d=(e₁−e_K)/√2（极端端元对角）。本文标定「**幅度**」和「**top1 何时失效**」：

- **幅度（待办 3）**：σ_err = **C / (√N·ρ₁ₖ)**，C ≈ 0.48 **与 K 无关**（ρ₁ₖ = erf((K−1)Δμ/(2√2σ)) = 极端对 KS 距离）。等价 adjacent-ρ 写法 σ_err = C/((K−1)·√N·ρ)，即前因子 c_K = C/(K−1)，**adjacent-ρ 下不是 K-无关**。解析：I_red ≈ 2π((K−1)ρ)²（高斯位置 Fisher），σ_err = κ/√π /(√N·ρ₁ₖ)，**κ = 0.85 是 KDE 对方差前因子的修正**（ρ,K-无关）。
- **失效（待办 2）**：top1 失效分两套机制。**endpoint k\***：â 越过 ½ 翻转，阈值 **√N·(K−1)·ρ·Δw ≳ c_top1 ≈ 0.34**（c_top1 = C/√2）。**interior k\***：钉扎直接杀死 k\* 权重 → top1 = 0（vertex jump），与 margin 无关，ρ>ρ_c 才恢复。

## §2 c 标定（待办 3）— 约化 2-极端端元 Fisher + KDE 修正

### §2.1 物理对象：约化 Fisher（不是连续 A 的中间本征值）

钉扎后只剩 2 个 survivor（极端端元 1, K），估计量退化为**单参数** â = argmin_a KL(X ‖ a·h₁+(1−a)·h_K)。其有限-N 方差由**约化 1-D Fisher** 控制：
　　**I_red = ∫ (h₁−h_K)² / q₀ dt**，q₀ = a·h₁+(1−a)·h_K（在总体 a_∞ 处）。
Var(â) ≈ 1/(N·I_red)，σ_err = √2·std(â) = **√2/√(N·I_red)**（√2 来自 ‖e₁−e_K‖）。

### §2.2 小ρ 闭式【解析】

h₁−h_K ≈ −(K−1)Δμ·∂_μ h（两端元中心相距 (K−1)Δμ，对单高斯一阶 Taylor）。高斯位置 Fisher ∫(∂_μh)²/h = 1/σ²。故
　　**I_red ≈ ((K−1)Δμ)²/σ² = 2π·((K−1)ρ)²**（用 Δμ = σ√(2π)·ρ 小ρ）。
〔确定性核验：K=3 ρ=0.04，I_red 精确 3.987×10⁻² vs 预测 2π((K−1)ρ)² = 4.021×10⁻²，**ratio 0.9915**。I_red 实测指数 +2.0。〕
代入：σ_naive = √2/√(N·I_red) = **1/(√(πN)·(K−1)ρ)**，即 **C_naive = σ_naive·√N·ρ₁ₖ = 1/√π = 0.5642**（K-无关）。

### §2.3 KDE 前因子修正 κ【确定性核验，回答待办 3 的 ⚠】

待办 3 ⚠「KDE 可能改前因子（不只标度）」。用 C1 实测 σ_err 比 §2.2 解析 naive：**κ = σ_meas/σ_naive，跨 K=3/4/5/6 × 5 个 ρ 共 18 cell**：
　　**κ = 0.847 ± 0.031（CV 3.6%，range [0.79, 0.92]），ρ- 与 K- 无关**（仅高 ρ 近饱和处轻微上漂）。
⟹ **KDE 对方差前因子是一个干净的 ρ,K-无关 ≈0.85 乘子（约 −15%）**，**不**改 ρ 标度（标度由约化 Fisher 给）。这本身是个结果：KDE 的大效应是制造**钉扎（bias）**，对 pairwise **方差**前因子只轻微压低。

### §2.4 最终标定律

**σ_err = C/(√N·ρ₁ₖ)，C = κ/√π = 0.847/1.7725 = 0.478 ≈ 实测 0.49（CV 5.3%）。**
- ρ₁ₖ = erf((K−1)Δμ/(2√2σ))（极端对 KS 距离；小ρ ≈ (K−1)ρ）。
- adjacent-ρ：σ_err = [C/(K−1)]/(√N·ρ)。
- 三个数自洽：C_naive·κ = 0.5642×0.847 = 0.478 = 实测 C。✓

## §3 top1 失效阈值（待办 2）

### §3.1 两套机制（C3-Part1 坐实）

钉扎区（ρ<ρ_c）内只有极端端元 {1,K} 存活，**top1 按 k\* 位置分裂**：

| k\* 位置 | 机制 | 钉扎区 top1 |
|---|---|---|
| **endpoint**（k\*∈{1,K}）| survive；â 越过 ½ 翻转（1-vs-K pairwise margin）| 高，按 §3.2 阈值 |
| **interior**（k\*∉{1,K}）| 钉扎杀死 ŵ_{k\*}=0 ⟹ argmax 永不等 k\* | **= 0（vertex jump）** |

〔C3 smoke（K=4 ρ=0.08，rho_c=0.19 深钉扎）：endpoint k\*=0 → top1=**1.000**、mean ŵ=[0.563,0,0,0.437]；interior k\*=2 → ŵ_{k\*}=**0.0**、top1=**0.000**。PRE7/PRE8 双 PASS。〕

**interior k\* 的 vertex jump = 主定理 §3/§5 的「顶点跳跃」**——现在有了机制：不是「runner-up 平滑越 margin」也不是含混的「k\* 塌向 0」，而是**钉扎确定性杀死所有内部端元**。top1 仅在 ρ>ρ_c（释放）才恢复。

### §3.2 endpoint pairwise 阈值【解析】

endpoint k\*（设 k\*=1），钉扎后 ŵ = (â,0,…,0,1−â)。top1 正确 ⟺ argmax = 1 ⟺ â > 1−â ⟺ **â > ½**。margin **Δw = a_∞ − ½**（存活分数距 ½ 的距离）。â 近似高斯 N(a_∞, std(â)²)，std(â) = σ_err/√2 = C/(√2·√N·ρ₁ₖ)。失效概率
　　P_flip = P(â < ½) = Φ(−Δw/std(â)) = Φ(−z)，**z = (√2/C)·√N·ρ₁ₖ·Δw**。
失效 onset（z ~ O(1)）：**√N·ρ₁ₖ·Δw ≳ C/√2 ≈ 0.34**，即
　　**√N·(K−1)·ρ·Δw ≳ c_top1，c_top1 = C/√2 ≈ 0.34**（K-无关常数，(K−1) 显式在外）。

### §3.3 与 HANDOFF / v0.2 双渠道的衔接

- HANDOFF 待办 2「√N·ρ·Δw ≳ c（K 无关）」**更正为 √N·(K−1)·ρ·Δw ≳ c**。(K−1) 来自极端对分离 ρ₁ₖ≈(K−1)ρ，**不是** adjacent ρ。「相邻端元混淆」措辞也微调：endpoint k\* 的竞争者是**另一极端端元**（1 vs K），非相邻。
- v0.2 §3 双渠道 top1 ≈ top1_max(ρ)·[1−P_flip] 框架**可复用**：P_flip 标度从 ρ^{K−1} → **ρ₁ₖ = (K−1)ρ**（不是 HANDOFF 说的裸 ρ）。top1_max(ρ) = 单颗锆石可分性天花板（与权重估计无关）不变。
- 〔注：§3.2 是 endpoint k\* 的渠道；interior k\* 的 top1 由 vertex jump 主导，P_flip 框架不适用，应单列。〕

## §5 遗留 open

1. **κ≈0.85 的解析来源**：现为确定性数值（C1 实测/解析 Fisher）。第一性原理推 κ 需 KDE 平滑算子对 score 协方差的修正（data Cov(X_kde) vs raw multinomial Fisher 的 sandwich）。~15% 修正、ρ,K-flat，值得补但非阻塞。
2. **c_top1 的判决阈定义**：c_top1 = C/√2 是 z~1（P_fail≈16%）口径；论文若按「top1<50%」或「<84%」定义临界，常数随 z-score 平移（z=0 给 P=50%，c=0）。需与相图失败率定义对齐。
3. **interior k\* 的 vertex-jump top1 律**：ρ<ρ_c 给 0、ρ>ρ_c 恢复，过渡形状（释放邻域）未标定——与 ρ_c 的 4 阶矩修正（curvature_freezing_proof §7.4）耦合。
4. **极端对超线性**：C 的 ~7% 上漂来自 ρ₁ₖ=erf((K−1)Δμ/2√2σ) 对 (K−1)ρ 的 erf 曲率偏离；大 K 显著，写论文用 ρ₁ₖ（非 (K−1)ρ 近似）即消。
