## 命题（v0.2 重构）

**引理 2（L²–Hessian 谱同阶，病态区 + 内部 w）.** 设工作点 w 满足 **min_k w_k ≥ δ > 0**（单纯形相对内部），端元间 KS 距离 **ρ 远离 1**（即引理 1 的病态区，κ_simplex 已发散）。记 KL 损失在真模型点 x=g 处的不动点 Hessian
　　**A(w) = H·diag(1/g)·Hᵀ**，g = Hᵀw，
在支撑集 **S = ∪_k [μ_k ± Mσ]**（M 固定常数）上取权重比 r_S(w,ρ) = max_S g / min_S g。则在 sum-to-one 切空间（基 Z）上
　　r_S^{−1}·κ(ZᵀHHᵀZ) ≤ κ(ZᵀA(w)Z) ≤ r_S·κ(ZᵀHHᵀZ)。
**在病态区 ρ→0：r_S(w,ρ)→1**（端元趋同 → g 趋单峰 → 峰谷比→1），夹逼塌成 [1,1]，故
　　**κ_Hessian ≍ κ_simplex ≍ ρ^{−2(K−2)}**（指数严格转移）。
常数随 1/min_k w_k（边界）与 ρ→1（端元远离、g 多峰）发散，但**后者无害**（那里 κ_simplex 本就 O(1)）。

> **本引理只交付两件事**：(a) κ_Hessian 与 κ_simplex **同阶**；(b) 病态区指数 **2(K−2) 严格转移**。**不交付**可用乘性常数（r_S 成立但松 1–2 个量级，且依赖 w）。

## 证明

Hessian 形式：D(x‖g)=Σ_t[x_t log(x_t/g_t)−x_t+g_t]，∂²D/∂w_k∂w_l=Σ_t(x_t/g_t²)H_{kt}H_{lt}，在 x_t=g_t 得 A(w)=H diag(1/g)Hᵀ。〔KDE 把计数变密度只改 x 标度，在 x=g 处 Hessian 形式不变——有限差分 1e-8 + multinomial MC 0.17% 三重确认。〕

任意 u：uᵀA(w)u=Σ_t(1/g_t)(Hᵀu)_t²。在 S 上 1/g_t∈[1/g_max,1/g_min] →
(1/g_max)·Σ_S(Hᵀu)_t² ≤ uᵀA(w)u ≤ (1/g_min)·Σ_S(Hᵀu)_t²，且 Σ_S(Hᵀu)²≈uᵀHHᵀu（注①）。
u=Zv 限切空间，Courant-Fischer（Loewner 单调）：λ_max(ZᵀAZ)≤(1/g_min)λ_max(ZᵀHHᵀZ)，λ_min(ZᵀAZ)≥(1/g_max)λ_min(ZᵀHHᵀZ)，相除得 κ 比 ≤ r_S = g_max/g_min。∎

**注①（v0.2 重写，补 v0.1 漏洞）** 两类"g_t 小"必须分开：
- **(远尾) t 远离所有峰**：g_t→0 但 (Hᵀu)_t→0 更快（被最近端元 m 主导，(1/g_t)(Hᵀu)²≈u_m²H_{mt}/w_m→0）→ **可忽略** ✓。这是 v0.1 处理的。
- **(低权重峰区) t 落在某 w_m≈0 的端元 m 峰心**：g_t≈w_m h_m(t) 小是因为 **w_m 小**而非 t 远；此处 (Hᵀu)_t≈u_m h_m(t) **最大**，(1/g_t)(Hᵀu)²≈u_m² h_m/w_m → **随 w_m→0 发散，是支配项不可忽略**。**这就是 κ_Hessian ∝ 1/min_k w_k 的来源**，v0.1 注①漏掉了它，故 v0.2 用 min_k w_k≥δ 前提显式排除。

## ⚠ 关键发现（影响 bounds 实验本身，需用户决策）
